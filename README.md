# Snake

A browser-based Snake game built with TypeScript and Vite.

## Setup

Requires [Node.js](https://nodejs.org/) (with npm).

```bash
npm install
npm run dev
```

This starts a local dev server (Vite) and prints a URL — open it in your browser to play.

Other scripts:

```bash
npm run build      # type-check and build for production
npm run preview    # preview the production build locally
npm run typecheck  # type-check only
```

## How to play

Eat the food to grow and score points. The game ends if the snake runs into a wall or itself.

**Keyboard**
- Arrow keys or `WASD` — move
- `Space` — pause / resume
- `Enter` — start, or restart after game over

**Touch**
- Swipe — move
- Tap — start, or restart after game over
